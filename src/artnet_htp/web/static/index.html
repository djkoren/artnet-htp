Mode sets how each source contributes: HTP sources merge channel-by-channel with each other (max wins). Priority sources override every HTP source when they have any non-zero data (e.g. set FPP to Priority so it takes over the rig when it’s active, then falls back to your HTP-merged Madrix when it goes to blackout). Among multiple active Priority sources, the one with the highest Priority number wins (200 beats 100).
